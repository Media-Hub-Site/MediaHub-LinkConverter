# 🔗 MediaHub — Link Converter (Downloader)

Descargador inteligente de contenido multimedia. Parte del ecosistema **Media Hub**.

## Plataformas soportadas
YouTube, TikTok, Instagram, Twitter/X, Facebook, Vimeo, Twitch y más.

## Tipos de descarga
- **Video**: MP4, MKV, AVI, WEBM, MOV
- **Audio**: MP3, WAV, M4A, FLAC, OGG
- **Imágenes**: Descarga directa de fotos

## Instalación
\\\powershell
pip install -r requirements.txt
\\\

## Ejecución
\\\powershell
python main.py
\\\

> Requiere FFmpeg instalado en el PATH.
> Parte del ecosistema [Media Hub](https://github.com/Media-Hub-Site)
